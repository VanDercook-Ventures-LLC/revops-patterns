# revops-patterns

Reusable patterns from real revenue-operations and automation work — extracted,
sanitized, and generalized. No client names, no client data, no internal figures.

Each pattern is a folder under `patterns/` with a README that states the problem,
the root cause, and the fix, plus the working code.

| Pattern | One line |
|---|---|
| [html-to-pdf-single-source](patterns/html-to-pdf-single-source/) | Derive the PDF from the page so they can never drift |
